General: Qwen3-Next-80B-A3B-Instruct

Same architecture as Qwen3-Coder-Next above, general-purpose instead of coding-tuned · port 8092

If the button doesn't work (server not running), run this from the project root instead: 
./gui/launch.sh qwen-next
Buttons POST to a local picker_server.py backend (if it's running) which shells out to gui/launch.sh <model>. That script starts the model CPU-only via bin/start-model.sh <model> --cpu-only if it isn't already up, then opens the model's built-in chat webui in its own app-mode browser window. Loading is slow on CPU-only — give it a minute after the button reports "launching".
